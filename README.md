# Upshot Insurance Website

## Quote Form Integration (Powered by Jotform)

The quote form on the website is powered by **Jotform** (Form ID: `263255342465054`).

### 1. View & Manage Submissions
- All quote submissions, customer details, and attached documents are automatically saved to your **Jotform Tables** at:  
  **https://www.jotform.com/tables/263255342465054**
- You can search, filter, download, or export leads to Excel/CSV at any time directly from Jotform Tables.

### 2. Email Notifications
- Instant email alerts are configured in your Jotform Dashboard under:  
  **Settings → Emails → Notification Email**
- You can add or change recipient email addresses without editing any website code.

### 3. Website Integration
- The Jotform embed code is integrated directly inside the modal popup in `index.html`.
- Any **"Get a Quote"** or service card button triggers the quote modal seamlessly.
- Responsive script (`for-form-embed-handler.js`) automatically resizes the form dynamically on mobile, tablet, and desktop devices.
